# Financy - Personal Finance Management

## Project Overview
Financy is a full-stack personal finance management application. It allows users to track their transactions, manage categories, and visualize their financial health.

The project is structured as a monorepo with two main components:
- **Backend:** A GraphQL API built with Node.js, Type-GraphQL, and Prisma.
- **Frontend:** A modern web application built with React, TanStack Router, and Tailwind CSS.

## Monorepo Structure
- `backend/`: Node.js GraphQL service.
- `frontend/`: React web application.
